# Nexus Office 6.45.4

A modern Home workspace with six balanced cards, crisp vector graphics, full-width desktop and 4K layouts. The Assistant and recent-document panels are removed from the GUI. Existing documents, stored history, workspace launch actions and the 6.45.3 Writer ribbon are preserved.

Open `Nexus_Office_v6_45_4_Browser.html` for the standalone edition. For the full source application, keep installer.py, package_manifest.json and all three numbered data parts together; follow INSTALL.txt. The complete download is `Nexus_office_6.45.4_Full.zip`.

An actual 3840 × 2160 Home image is in docs/Nexus_Office_6.45.4_Home_4K.png. See docs/CHANGELOG_6.45.4.md and RELEASE_VALIDATION.json for implementation and checks. The prior Writer Word guide is retained for the ribbon; its Assistant-layout guidance is superseded by this release.
