# Nexus-Office 6.45.1

Both the installed application and browser edition include the updated assistant dock, header and composer. Writer distributes ribbon groups across the available width and adapts its controls and ruler to narrower windows, including when the assistant is pinned. Writer’s ribbon wraps and grows across the available width. On short screens, a bounded, scrollable tool area preserves document space. All controls remain accessible, but are not necessarily visible at the same time. This is a presentation update; commands, document formats, models and editing capabilities are unchanged.

Previous release 6.45.0 is retained unchanged. No new throughput result, model compatibility claim or physical Windows/Radeon qualification is introduced by this UI patch.
