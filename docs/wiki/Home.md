# Nexus Office

[Open the browser trial](https://rdunbar01.github.io/Nexus-Office/Nexus_Office_v6_45_0_Browser.html) · [Repository](https://github.com/RDunbar01/Nexus-Office)

Nexus Office 6.45.0 combines Writer, Grid, Present, Paint and Dashboard. The browser trial, packaging revision 1, contains the existing application's code and assets in one HTML file. The monolithic format makes online evaluation straightforward and permits downloading one file for local use.

## Capabilities

Edit documents and workbooks, use presentation layouts, work with visual assets and create dashboard snapshots. Bounded Office commands use literal inputs, contextual previews and approval before edits. Writer changes use the existing Undo workflow. The bundled learned checkpoint is not qualified or enabled as a general-purpose Office agent.

## Start and requirements

Open the trial link in a current desktop browser with DecompressionStream, TextEncoder/TextDecoder and Web Crypto. Bundled data is expanded and checked locally before the application notice appears. No Python, PyTorch or CDN is required for startup. The distributed file is below 20,000,000 bytes; its expanded application and memory requirements are larger. Startup time depends on the device.

The unchanged full 6.45.0 package remains in the repository. CPython 3.12 is recommended for its optional installer. The old package's candidate.html needs its two companion scripts; the new trial does not.

## Boundaries and validation

Supported imports and exports are format-specific; perfect Microsoft Office fidelity is not promised. Clipboard, printing and rendering depend on the browser. Do not treat the included checkpoint as a conversational agent or the command interface as an arbitrary macro engine. See [build and test details](https://github.com/RDunbar01/Nexus-Office/blob/main/docs/BROWSER_TRIAL.md) for test scope and limitations.
